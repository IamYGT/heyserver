# Project Sustainability

Heyserver's core source is licensed under Apache License 2.0. Installing the panel
on additional servers, contributing changes, and redistributing compliant forks
do not require a per-server license from this repository.

## Current model

- Public source and release artifacts remain provider-neutral.
- Community support uses public issues and the support workflow.
- Vulnerabilities use GitHub's private advisory channel.
- No paid edition, domain limit, telemetry requirement, hosted dependency, or
  license-key gate is part of the current product contract.

## Sustainable funding options

The project may later fund maintenance through clearly separated services such
as hosted infrastructure, migration assistance, support agreements, training,
or independently packaged integrations. Any proposal must preserve the public
license for already released code and must not introduce an operator-specific
runtime dependency into the community core.

## Decision requirements

A material sustainability proposal should be public before implementation and
state:

1. which artifact or service is funded;
2. what remains available in the Apache-2.0 core;
3. whether data, authentication, or network boundaries change;
4. how community contributors are affected;
5. how an installation continues operating if the optional service disappears.

There is currently no approved pricing, paid tier, commercial feature matrix,
or revenue target in the public project.
